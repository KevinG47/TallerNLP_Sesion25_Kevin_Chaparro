# Taller NLP - Sesión 25

**Kevin Chaparro**
Estadística — Universidad Santo Tomás | Semestre 2026-I

En este taller analica el informe "Estudios Económicos de la OCDE: Colombia 2024" usando tecnicas de procesamiento de lenguaje natural con PySpark. El trabajo incluyo extraccion de texto desde PDF, limpieza, tokenizacion con dos metodos distintos, analisis de frecuencias, verificacion de la ley de Zipf y calculo de metricas como el TTR y cobertura del vocabulario. Aprendi que decisiones aparentemente simples como la eleccion del tokenizador pueden afectar todos los resultados, y que el patron \W+ no es adecuado para textos en español por el problema con las tildes.
